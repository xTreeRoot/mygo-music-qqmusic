# QQ 音乐插件 · MB / MyGo

**0.3.6**，同一份插件用于 MB 桌面、iOS 和 Android。最低宿主兼容版本为 **MyGo 0.1.20**；移动端需支持 JavaScript 插件的 MB 版本。纯 JavaScript 直接连接腾讯服务，无需 API 服务、Node 后台、ffmpeg 或 Google 服务。

本项目由 xTreeRoot 维护，基于 [Lorpaves/mygo-music-qqmusic 0.3.5](https://github.com/Lorpaves/mygo-music-qqmusic)，继续保留 Amamiya23 上游历史及 AGPL-3.0、第三方许可证。来源见 [NOTICE.md](NOTICE.md)。

## 安装

在 MB 的「设置 → 插件」中选择从 GitHub 安装，输入：

```text
xTreeRoot/mygo-music-qqmusic
```

也可以从 [最新 Release](https://github.com/xTreeRoot/mygo-music-qqmusic/releases/latest) 下载 `plugin.zip` 后导入。桌面、iOS、Android 使用同一个 ZIP，无需解压或安装 npm 依赖。按宿主提示允许清单中的腾讯 API、封面及音频域名。

插件 ID 为 `qqmusic`。与其他相同 ID 的 QQ 音乐插件共用安装位置，覆盖前请核对来源。已有 Lorpaves 版本的本地会话沿用原存储键；本次更新不会主动删除它。

## 登录

默认使用**微信扫一扫**；需要 QQ 扫码时，在插件设置「扫码登录方式」填写 `QQ`。留空、`wechat`、`wx` 和 `微信` 均使用微信。

1. 选择 QQ 音乐，点击登录。
2. 使用对应应用扫描二维码并确认授权。手机上操作时，可用另一台设备扫描；同机识别相册二维码取决于微信或 QQ 自身支持情况。
3. 验证成功后显示账号并加载个人资源。

取消登录会停止轮询、定时器和网络请求，并忽略迟到结果。退出仅停用本地会话，保留凭据与资料；再次登录先向腾讯验证已有会话，有效时直接恢复，确认失效后再提供新二维码。临时网络错误不会清空账号，也不会自动改成新扫码。

账号数据通过 `host.storage` 保存在宿主管理的插件数据目录，属于本地明文数据，不使用系统钥匙串，不进入仓库或发行包。退出不会撤销腾讯服务端其他设备的会话。

## 功能

- 搜索歌曲、歌手、专辑和歌单，支持搜索建议及分页。
- 精选歌单、排行榜、专辑、歌手页及评论读取；首页分区提供「更多」入口。
- 登录后读取个人歌单、喜欢的歌曲、收藏专辑、个人推荐和私人电台。
- 保留上游喜欢歌曲、收藏专辑和歌单编辑能力。
- MP3 标准 / 高音质、FLAC 无损；请求失败或未取得对应音源时按既有策略降档，并返回真实音质。
- 普通歌词、翻译及 QRC 逐字歌词，中文和 emoji 不依赖移动宿主缺少的 `TextDecoder`。

播放权限、音质及地区版权取决于 QQ 音乐账号权益。插件仅使用服务端返回的音源。搜索主接口返回 2001 时回退公开 Web 搜索；此时歌手 / 专辑结果来自歌曲元数据。

## 本次适配

- 移除歌词对 `TextDecoder` 的依赖，兼容移动端 QuickJS。
- 实现宿主 `cancelSignIn()` 合同，覆盖请求头、响应体和扫码等待期间的取消。
- 退出后保留账号，重新登录先验证复用；取消、旧请求和失败刷新不得覆盖新账号。
- 微信会话刷新校验账号 ID，拒绝刷新结果串号。
- 补充在线响应实际使用的封面 / 音频域名和媒体请求头。
- 同时提供已构建源码入口与独立 ZIP，供远程更新和本地导入使用。

## 开发与复现

```sh
npm ci
npm run build
npm test
npm run check
npm run test:live
node scripts/check-qr-live.mjs
python3 scripts/package.py
```

`index.js` 是源码入口，仓库清单指向 `dist/index.js`；发行 ZIP 的清单指向同目录 `index.js`。构建后提交 `dist`，CI 会检查构建结果与提交内容一致。打包使用公开文件白名单，不包含账号和设置。

可选真实运行时检查（只读访问 MB 仓库，产物和合成账号存储均放临时目录）：

```sh
MOEJS_HOST_DIR=/path/to/MB sh scripts/test-desktop-runtime.sh
python3 scripts/test-mobile-runtime.py --mb /path/to/MB
```

桌面检查需要与 MB `go.mod` 匹配的 Go；移动检查需要 Python 3、Clang 及本地 MB 的 `ios` / `android` 引用。可选密码运算回归使用 `MOEJS_HOST_DIR` 环境变量，`go` 必须指向项目要求的工具链。

`npm run test:signed-in` 为上游保留的只读账号检查，必须自行确认插件数据路径，未在本次验证中执行。账号写入操作仅用合成响应测试，没有创建、删除或修改线上歌单或收藏。
